# Absa Ghana — Mobile Banking Prototype

An interactive front-end prototype exploring a mobile banking experience for Absa Ghana. It includes iPhone and Android previews and sample banking screens and flows.

## Run it

Open `Absa Ghana — Mobile Banking.html` in a web browser. No installation or build step is required.

## Note

This is a design prototype for demonstration purposes. It uses fictional sample data and is not connected to Absa or any banking service.
